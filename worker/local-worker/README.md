# Local Worker (Personal-mode) - Advanced & Risky

This folder contains a template for a local worker that runs on the user's device (Termux) and may automate actions using user sessions.
**Important warnings:**
- Automating personal accounts using headless browsers or web automation (for Facebook, Instagram, WhatsApp personal) can violate terms of service and lead to account bans.
- This code is provided as a template only. Do NOT run it on central servers. If you choose to run any automation for personal accounts, run it on your personal device and accept full responsibility.
- We highly recommend using the share-intent human-in-loop approach instead (client-side).

The template below is intentionally empty of automation code. If you want a local worker, use the share-intent flow in the client or implement per-device automation at your own risk.
